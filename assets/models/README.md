# حزمة النموذج المنفصلة

يحمّل GitHub Actions ملفات نموذج Quran-Lab Zipformer v3.1 والرموز والمعجم والرخصة والـ manifest بعد التحقق من صلاحية الوصول، ثم يرفعها كـ Artifact منفصل باسم `rafiq-model-v3.1-pack`. لا تضف `assets/models/` إلى قائمة Flutter assets في `pubspec.yaml`؛ وإلا سيكبر APK بالحجم الكامل للنموذج.

في أول تثبيت، نزّل الـ artifact وفك ضغطه على الهاتف، ثم اختر الملفات الخمسة من شاشة البداية. يتحقق التطبيق من SHA-256 ونسخة النموذج قبل نسخها إلى مساحة التطبيق الخاصة. يبقى النموذج بعد تحديث APK العادي، لكنه يُفقد إذا أزلت التطبيق أو مسحت بياناته. يمكن إعادة إصدار artifact عبر `workflow_dispatch` مع `include_model_pack=true`.
